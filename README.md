# Fratellos Fútbol Club ("El Frate") — Landing Page Oficial

Landing page oficial de **Fratellos Fútbol Club** de Comodoro Rivadavia, Chubut (Patagonia Argentina).
Construida con **Astro + Tailwind CSS** para máximo rendimiento y mínimo consumo de recursos, lista para desplegar en **Vercel**.

## Desarrollo local
```bash
npm install
npm run dev
```

## Despliegue en Vercel
Importar el repositorio `Tomacods/Fratellos-FC` directamente desde el panel de Vercel (detecta Astro automáticamente).
